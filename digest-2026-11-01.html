    1. Jake Stauch：企业里自主 agent 的关键是护栏和审批

    Taking on ServiceNow: Coding Agents the Rest of Us with Serval Co-Founder and CEO Jake StauchNo Priors

    10-29 18:00

    Serval 做企业服务管理和自动化，对标 ServiceNow。Jake Stauch 说他是在上一家公司 Verkada 长期和 IT 团队打交道时发现这个方向的：ServiceNow 需要大量前期部署，跟不上企业想做的自动化，而且越来越贵。Serval 的做法是让 编码 agent 在底层干活，上面加抽象层、护栏和控制，所有改动都要走审批、预发和审计记录，让 IT 部门再把能力推广到 HR、财务和法务。

    他说企业想让 agent 足够自主、不用人盯，但自主在企业里很吓人；让 agent 随意写代码去操作所有系统是「无上限的安全风险」，Serval 的定位就是这道边界。谈到「SaaS 末日」时，他说试过用 vibe coding 自建核心记录系统的公司都发现，构建和维护企业软件依然很贵。Serval 还会派部署策略师和驻场工程师上门实施，并组建了专门的自动化工程团队来承接客户后续的长尾需求。
