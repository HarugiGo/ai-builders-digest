    一颗大模型芯片，藏着 Momenta 三年前的判断晚点 LatePost

    11-01 09:11

    晚点写 Momenta 系芯片公司 XHEART（新芯航途）10 月 29 日发布的 大模型芯片 X7 Ultra：大模型算力 700 TOPS，用超大核 NPU 把原本在多个小核之间百 GB/s 级的数据交换挪到核内以 TB/s 级完成，并为 Transformer 的高频计算加了专用加速单元。官方数据称在量产智驾模型上 NPU 利用率 98.7%，内存带宽消耗比「行业旗舰」降 80%、能效提高 100%。

    Using Agents for Long-Horizon Financial Work — Aman Singh, ArcaLatent Space

    11-01 00:00

    Arca 刚融资 6400 万美元，是一家 AI 原生的财富管理公司。Aman Singh 说 Arca 不是 SaaS 公司，而是自己就是这家理财机构；AI 不替代顾问，而是替代顾问周围的所有工作，客户不直接和 AI 打交道。模型以 Claude 为主，按任务复杂度给模型分档，税务分析这类任务用最重的一档（Opus 档、Sonnet 档或重型 GPT 模型），后台杂活用低档模型，选型看内部基准而不是外部榜单，自研了与模型无关的 harness，也不打算依赖 Anthropic 的 managed agents，因为不想把记忆和业务知识交给供应商。

    他用一个十万美元税单的例子说明分工：分析持仓、找出最优变现方案由 agent 全自动完成，但资金流动、清仓和直接联系客户都必须有人审批。长周期任务靠每位客户的记忆系统和定期「做梦」式反思来接续；每次写数据都有快速的 LLM 校验，入口处检测提示注入，数据外发时用确定性规则加小模型共识防泄露，所有人和 agent 的操作都有变更日志，方便合规审计。他的说法是「agent 提示人比人提示 agent 更多」。
