    Introducing Gemini 4 NeonDeepMind

    11-19 05:35

    Google DeepMind 推出 Gemini 4 Neon，把它放在 Carbon 与 Hydrogen 之间，强调以更快的端到端速度完成复杂软件工程、知识工作和科学任务。官方称，Neon 在 Artificial Analysis Intelligence Index 的 xhigh 档以 61 分排第 3，落后于更大、更慢的模型；在 Vals Index 上排第 2，并落在帕累托前沿。它在新的 Agent Arena Index 的可操控性（对任务中途纠正的适应）上排第 2，并称在 Google Antigravity 的内部测试中录得迄今最低的编造率。API 定价为每百万 token 输入 3 美元、缓存输入 0.15 美元（九五折）、输出 15 美元，上下文窗口为 100 万 token。当天起在 Google AI Studio 的 Gemini API、Gemini for business，以及向付费 Pro 和 Ultra 用户开放的 Antigravity 和 Gemini 应用中推出。文中还给出一组评测：Vals Index 70.9%、Legal Research Bench 与 Tax Agent Bench 均列第 1，Agents’ Last Exam v1.1 为 75.8%，Zapier AutomationBench 56.3% 与 Andon Labs Vending-Bench 2（16843 美元）均列第 1；科学侧在 Terminal-Bench Science（70.5%）、RiemannBench（84.0%）和 HLE-Diamond（71.3%）称最佳；编码侧在 Artificial Analysis Coding Agent Index 以 58.6 分排第 1，Terminal-Bench 4.1 为 65.2%，FrontierCode 2.0 在默认 high 设置为 46.2%。在 Antigravity 里，它也可作为编排器调度并行的 Hydrogen 子智能体。

    How OpenAI’s Performance Factory keeps ChatGPT fastOpenAI

    11-19 16:00

    OpenAI 技术员工 Okay Zed 和 Cyrus Forbes 介绍公司用 Codex 搭建的 Performance Factory：一套在云端运行、自动发现并修复性能问题的系统，用来跟上智能体开发的速度。工程师为重复任务定义工作流并给 Codex 写指令。其中回归工作流会在性能告警触发时开任务，由智能体调查、记录结论并提交修复供工程师审阅，部署后再由另一个智能体检查是否回到基线。文中写，这套工作流在三个多月里跟踪了逾 1700 次调查，定位了 600 多起根因，相当于每天约 17 次自动调查。团队还把排查流程写成名为 perf-forensics 的技能，系统由任务追踪与可配置工作流、分配循环、云端运行 Codex 的 API，以及在代码审阅或部署完成后唤醒智能体的订阅组成。
